# Карта результата LCT

Локальная карта на React, TypeScript, Vite и MapLibre. Показывает сохранённые результаты Java-сервиса на конкурсном наборе — побайтные копии `results/final_main.geojson` и `results/final_strict.geojson`. Свой файл рассчитывается и показывается в техническом интерфейсе сервиса. Нужен Node.js 22 (≥ 22.12) или 20 (≥ 20.19).

## Запуск

```bash
cd viewer
npm ci
npm run test:policy
npm run typecheck
npm run build
npm run dev
```

Откройте http://localhost:5173/viewer/.

Технический интерфейс сервиса — http://localhost:8080/, если сервис запущен.

## Режимы правила §2.2

- **Основной режим** — по умолчанию. Ввод в здание через ближайшую точку внешнего контура, а если прямой выход оттуда закрыт или из него нет допустимой трассы — через другую точку внешнего контура (дополнительные разъяснения 29.09, №15).
- **Строгий §2.2** — отдельная выгрузка для сравнения: глобально ближайшая точка всей границы, включая стены дворов. Его метрики не смешиваются с основным.

Обоснование и цитаты из документов находятся в [`../docs/TERMINAL_POLICY_DECISION.md`](../docs/TERMINAL_POLICY_DECISION.md).

## Что есть на карте

Карта поддерживает 3D и вид сверху, перемещение, масштабирование, поворот и наклон, слои и легенду, подписи ДУ и расхода, камеры, источник, ограничения, подсветку общих участков, карточку выбранного объекта и объяснение неподключённых точек.

## Согласованность данных

Из корня: `python3 scripts/sync_viewer_data.py` копирует три эталонных GeoJSON и записывает манифест с SHA-256.
`python3 scripts/sync_viewer_data.py --check` завершится ошибкой при отсутствующей или устаревшей копии.
Данные включены в git; для первого запуска не нужны сервис или ручное копирование.

Причины неподключения берутся из `variant_summary.diag_unconnected_reasons`. Необязательные файлы доказательств
расширяют визуализацию, но их отсутствие не убирает объяснение. Тип новых камер берётся из boolean `diag_tie_in`;
расстояние до сети используется только для старых файлов без этого свойства.

MapLibre 6.4.1 включает исправление XSS; Vite собирает отдельный worker из npm-пакета.
Политика и подготовка данных покрыты 7 тестами. Проверки этой версии — в `../docs/EXPERT_FEEDBACK.md`, сдачи 30.09 — в `../FINAL_RELEASE_REPORT.md`.

# Карта результата LCT

Локальный viewer на React, TypeScript, Vite и MapLibre. Он показывает фактические GeoJSON-результаты Java-сервиса.

## Запуск

```powershell
cd viewer
npm ci
npm run test:policy
npm run typecheck
npm run build
npm run dev
```

Откройте http://localhost:5173/viewer/.

Технический интерфейс Spring-сервиса работает на http://localhost:8080/, если запущен backend.

## Режимы правила §2.2

- **Строгая трактовка** — режим по умолчанию и вариант для сдачи. Использует глобально ближайшую границу здания.
- **Альтернативная трактовка** — отдельный output с раскрытым свободным выходом для спорных точек. Его метрики не смешиваются со strict.

Обоснование и цитаты из документов находятся в [`../docs/TERMINAL_POLICY_DECISION.md`](../docs/TERMINAL_POLICY_DECISION.md).

## Что есть на карте

Карта поддерживает 3D и вид сверху, перемещение, масштабирование, поворот и наклон, слои и легенду, подписи DN и расхода, камеры, источник, ограничения, подсветку общих участков, карточку выбранного объекта и объяснение неподключённых точек.

## Согласованность данных

Из корня: `python scripts/sync_viewer_data.py` копирует три authoritative GeoJSON и записывает SHA-256 manifest.
`python scripts/sync_viewer_data.py --check` завершится ошибкой при отсутствующей или устаревшей копии.
Данные включены в git; для первого запуска не нужны backend или ручное копирование.

Причины неподключения берутся из `variant_summary.diag_unconnected_reasons`. Optional proof-файлы расширяют
визуализацию, но их отсутствие не убирает объяснение. Тип новых камер берётся из boolean `diag_tie_in`;
расстояние до сети используется только для старых файлов без этого свойства.

MapLibre 6.4.1 включает исправление XSS; Vite собирает отдельный worker из npm-пакета.
Политика и подготовка данных покрыты 7 тестами. Фактическая проверка карты — в `../FINAL_RELEASE_REPORT.md`.

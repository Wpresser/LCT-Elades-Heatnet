# Синтетические сценарии

Проверка обязательных типов ограничений таблицы 2, которых нет в конкурсном наборе, и пограничных случаев.

```bash
cd scenarios
../validator/.venv/bin/python make_scenarios.py          # пересоздать входы
cd ../service && ./mvnw -q -Dtest=ScenarioTest test        # решить все сценарии → target/scenarios/*/result.geojson
cd ../scenarios && ../validator/.venv/bin/python check_scenarios.py
```

| Сценарий | Что проверяет |
|---|---|
| road_crossing, tram_crossing | спецпроход через полигон: угол ≥ 45°, полигон + 3 м, K 1,60 / 1,75 |
| gas_crossing, cable_crossing | спецпроход через линию: ± 2 м (+ зона отступа, DECISIONS №28), K 1,25 / 1,15 |
| park_between, social_and_prohibited | обход запретных площадных объектов с отступом 1 м, проход в щели 4 м |
| road_with_gas | наложение спецпроходов: деление при смене набора, K = наибольший |
| cross_existing_network | пересечение существующей теплосети без врезки, K 1,05 |
| unreachable_island | цель за кольцом воды не подключается, остальные — да (частичный результат) |
| string_ids_two_in_one | строковые id, две цели в одном здании |
| target_outside_building | точка подключения вне здания — трасса начинается прямо от точки |
| no_network | нет существующей сети — все цели не подключены, результат формируется |
| pipe_under_road | существующая труба внутри полигона дороги: спецпроход заканчивается в камере присоединения |
| dirty_input | 3D-координаты, повторяющиеся точки, ДУ не из таблицы, самопересекающийся полигон, id-строки из цифр, объект без геометрии, неизвестный тип ограничения |
| city_dense | плотный квартал: 256 домов, проезды 12 м, 25 целей — все должны подключиться (`make_city.py`) |

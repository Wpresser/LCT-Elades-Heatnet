# Материалы конкурсного задания

В каталоге `sources/` находятся официальное ТЗ, актуальное техническое приложение, письменные разъяснения, исправленный конкурсный GeoJSON и дополнительные разъяснения от 29.09.2026 (переданы участнику команды; публичная ссылка организатора не установлена). В `text/` лежат текстовые копии документов для поиска.

[`DATA_AUDIT.md`](DATA_AUDIT.md) описывает проверенные свойства набора данных, а [`SOURCE_MANIFEST.json`](SOURCE_MANIFEST.json) содержит сведения об исходных файлах и их SHA-256.

При расхождении документов ориентируйтесь на актуальное техническое приложение и официальные разъяснения. Решение по правилу §2.2 приведено в [`../docs/TERMINAL_POLICY_DECISION.md`](../docs/TERMINAL_POLICY_DECISION.md).

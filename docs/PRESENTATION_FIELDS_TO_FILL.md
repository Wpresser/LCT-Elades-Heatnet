# Данные презентации

В текущей презентации заполнены название команды, учебное заведение, город, Telegram, телефоны, история команды и фотографии участников.

Метрики на слайдах — основной режим `relaxed` (доп. разъяснения 29.09, №15; `results/final_main.geojson`). Строгое прочтение `literal` (`results/final_strict.geojson`) показано только для сравнения.

# Сценарий демонстрации

1. `docker-compose up --build -d` (или `docker compose up --build -d`): сервис на http://localhost:8080/, Swagger — `/swagger-ui.html`.
2. Из корня: `python3 scripts/api_e2e.py` — загрузка конкурсного набора, запуск, ожидание `DONE`, скачивание результата
   и три независимые проверки; выгрузка побайтно совпадает с `results/final_main.geojson`. По умолчанию
   `HEATNET_TERMINAL_POLICY=relaxed`.
3. Заранее, до показа: в техническом интерфейсе (http://localhost:8080/) загрузить `scenarios/osm_roads/enriched.geojson` —
   тот же квартал с полигонами дорог OpenStreetMap. Расчёт идёт 2–3 минуты, задания сохраняются в базе. На показе
   открыть его из списка «Последние расчёты»: трассы держат коридоры вдоль улиц и пересекают дороги под углом не меньше 45°.
4. `cd viewer && npm ci && npm run dev` — карта на http://localhost:5173/viewer/ (Node.js 22 или 20.19+).
5. Основной режим открыт по умолчанию: 17/17, S 13,197, 1,846 км, 273,6 млн ₽, штрафа нет. Показать точки 2, 5, 10:
   ввод через внешний контур здания (дополнительные разъяснения 29.09, №15), точка 5 — не через двор.
6. Показать инженерные подписи ДУ и расхода, общие магистрали, камеры, источник, слои, 3D и вид сверху.
7. Для сравнения переключить «Строгий §2.2»: 14/17, S 20,589, 568,9 млн ₽, из них штраф 339,0 млн ₽.
   Нажатие на неподключённую точку показывает причину и штраф по §2.5 / §6.

Точные значения и варианты по рангу — `FINAL_METRICS.json`. Проверки этой версии — `docs/EXPERT_FEEDBACK.md`;
проверки сдачи 30.09 — `FINAL_RELEASE_REPORT.md` (история). Нагрузочные замеры 3 ГБ / 50 клиентов сделаны 28.09
на промежуточной сборке и в демонстрацию не входят.
